# Try and install EVA

1. Download the **x86_64 beta ISO** from the download link on the presentation page.
2. Prepare a bootable USB. With an existing Ventoy USB, copy the ISO onto it and select it at boot.
3. Start the Live session and check displays, keyboard, audio, network and graphics on your computer.
4. Open EVA's welcome window and launch the graphical Calamares installer.
5. Review the destination and partition changes before applying them. Back up files you want to keep.
6. After installation, choose a boot theme in **Settings → Boot · GRUB**.

The download folder and screenshots are independent: screenshots can show a newer development build. Check the ISO filename and date when downloading.
